# LibreOffice

The desktop release archives include an unmodified LibreOffice installation
from The Document Foundation. LibreOffice is free and open source, primarily
under MPL 2.0 and LGPL 3.0 or later, with separately licensed components.
Its complete license and attribution files remain inside the bundled
`LibreOffice` folder (Windows) or `LibreOffice.app` (macOS).

Source code for the corresponding LibreOffice release is available at
https://download.documentfoundation.org/libreoffice/src/ . The installed
version is reported by `soffice --version` from the bundled runtime.
