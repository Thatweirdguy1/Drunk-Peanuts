## Drunk Peanuts 0.25.0

Tables now displays calculated results in cells while retaining formulas in the formula bar, editor and saved files. It adds automatic recalculation, AutoSum, F9, Show formulas, common number-format display, formula-based chart values and IF/IFERROR, ROUND/ABS, COUNTA and logical functions. Unsupported/error formulas display explicit error states.

PDF→DOCX now preserves complete rendered pages by default, retaining graphical letterheads, images and signatures. These pages are images, not editable text. The alternative is clearly labelled Text only (drops images/layout). The reported one-page sample was checked locally without modifying its original.

88 tests pass. See the [feature and preservation report](https://github.com/Thatweirdguy1/Drunk-Peanuts/blob/main/docs/FORMULAS_PDF_025.md) for calculation/conversion limits. Personal sample content is excluded from the public repository.
