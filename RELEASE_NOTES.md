## Drunk Peanuts 0.21.2

FreeConvert is now **Drunk Peanuts**, with an original DP icon and a black, purple and yellow desktop theme. The repository and download names are updated to Drunk-Peanuts / DrunkPeanuts.

Pages adds header/footer text, native Word PAGE/NUMPAGES fields, alignment, starting numbers and a first-page option. Preview bands show authored content; PDF export numbers the actual output pages. Header-only edits preserve imported body XML, fields and images. The Microsoft 365-style Office ribbon remains available.

78 source tests pass. Installed Word recognized the native fields and exported a correctly numbered two-page fixture. Platform builds validate packaged Office, OCR, playback and conversion before release.
